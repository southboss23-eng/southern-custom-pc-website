# Southern Custom PC & Hardware LLC Website

A static, mobile-friendly website prepared for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — blue/gold responsive design
- `script.js` — mobile navigation, animations, date handling, back-to-top
- `images/logo.jpg` — business logo

## Publish on GitHub Pages
1. Create a new public GitHub repository.
2. Extract this ZIP file on your device.
3. Upload the CONTENTS of `Southern-Custom-PC-Website` to the repository. `index.html` must be at the repository root.
4. Commit the files.
5. Open Settings > Pages.
6. Under Build and deployment, choose "Deploy from a branch".
7. Select `main` and `/ (root)`, then save.
8. Wait for GitHub to publish the site.

## Before launch
- Replace the generic Facebook URL in `index.html` with the exact business Facebook page URL.
- Add real project photos to the gallery when available.
- Test the appointment form. FormSubmit may send an activation email to the business email the first time it is used.
- Confirm business hours and all contact details before advertising the site.

## Gallery
The current gallery intentionally uses placeholders so the site does not claim stock photos are your actual work. When you have photos, add them to the `images` folder and replace the placeholder `<div>` elements with `<img>` elements.

## Appointment form
The form is configured to submit through FormSubmit to the business email. This is a third-party service; test it before launch.
